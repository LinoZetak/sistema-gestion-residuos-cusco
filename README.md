# Sistema de Gestión de Residuos - Cusco

Aplicación web orientada a mejorar la gestión de residuos en la ciudad de Cusco mediante el seguimiento de recolección, optimización de rutas y comunicación con los ciudadanos.

---

## 🎯 Visión del Producto

- **Para:** Municipalidad, ciudadanos y operadores de camiones  
- **El sistema:** Plataforma web de gestión de residuos  
- **Que permite:** Monitorear rutas, reportar problemas y optimizar la recolección  
- **A diferencia de:** Procesos manuales o sistemas no integrados, ofrece seguimiento en tiempo real y mejor coordinación  

---

### Solución
- Sistema web con monitoreo de rutas  
- Reporte ciudadano de incidencias  
- Integración con GPS  

### Propuesta de valor
Optimizar la gestión de residuos urbanos mediante tecnología que mejora la eficiencia, reduce costos y mejora la experiencia ciudadana.

### Usuarios
- Municipalidad  
- Ciudadanos  
- Operadores  

---

## ⚠️ Riesgos Iniciales

- Baja adopción del sistema

- Resistencia al cambio por parte de operadores
